Como o Projeto Funciona

Visão geral da arquitetura, arquivos e fluxo de dados

O Dashboard Clima & Notícias é uma aplicação web de página única (SPA) construída com HTML5, CSS3 e JavaScript puro — sem frameworks ou etapas de build. Ao abrir o index.html no navegador, a aplicação carrega os dados de clima e notícias em tempo real via Fetch API e os exibe de forma dinâmica no DOM.

Estrutura de Arquivos

News_and_weader/ ├── index.html # Página principal — estrutura HTML do dashboard ├── css/ │ ├── style.css # Estilos globais, variáveis CSS e layout Grid │ └── responsive.css # Media queries (mobile-first) ├── js/ │ ├── weather.js # Integração com OpenWeatherMap API │ ├── news.js # Integração com GNews API │ └── main.js # Inicialização, eventos e gráfico Chart.js ├── assets/icons/ # Pasta para ícones SVG ├── wireframe.html # Wireframe acadêmico do projeto └── README.md # Documentação resumida

Papel de Cada Arquivo JavaScript

ArquivoResponsabilidade
weather.js Contém as funções fetchWeather() e fetchForecast() que chamam a OpenWeatherMap API, além de renderCurrentWeather() e renderForecast() que montam os cards no DOM.
news.js Contém fetchNews(), que busca as últimas notícias do Brasil na GNews API, e renderNews(), que gera os cards de notícia com imagem, título, descrição e link.
main.js Centraliza a inicialização: chama fetchNews() ao carregar a página, registra os event listeners da barra de busca e renderiza o gráfico de temperatura via Chart.js.

Chaves de API

Como criar as contas, obter as chaves e configurá-las no projeto

O projeto depende de duas APIs externas gratuitas. Cada uma exige uma chave de autenticação que deve ser inserida nos arquivos JavaScript antes de usar o dashboard.

APIFinalidadeLimite gratuitoSite
OpenWeatherMap Clima atual e previsão 5 dias 1.000 requisições/dia openweathermap.org
GNews API Notícias brasileiras em português 100 requisições/dia gnews.io

1. OpenWeatherMap — Obter a chave

1
Criar a conta

Acesse openweathermap.org e clique em Sign Up. Preencha nome, e-mail e senha, depois confirme o e-mail recebido.

2
Acessar o painel de API Keys

Após o login, clique no seu nome no canto superior direito → My API keys. Uma chave padrão já estará criada.

3
Copiar a chave

Copie a chave exibida (sequência de 32 caracteres). Ela pode levar até 10 minutos para ativar após o cadastro.

2. GNews API — Obter a chave

1
Criar a conta

Acesse gnews.io e clique em Get API Key. Preencha o e-mail e senha, depois confirme pelo link enviado ao e-mail.

2
Acessar o painel

Após o login, a chave aparece diretamente na página inicial do painel (dashboard). Não é necessário navegar em outros menus.

3
Copiar a chave

Copie a chave exibida. A GNews disponibiliza a chave imediatamente após o cadastro — não há período de ativação.

Configurando as Chaves no Projeto

Onde e como inserir as chaves nos arquivos JavaScript

As chaves de API são inseridas diretamente na primeira linha de cada arquivo JavaScript. Abra os arquivos no editor de texto de sua preferência e substitua o placeholder 'SUA_CHAVE_AQUI' pela chave real obtida no passo anterior.

Arquivo js/weather.js — Chave do OpenWeatherMap

Abra o arquivo js/weather.js e localize a linha 1:

// ANTES (placeholder) const WEATHER_API_KEY = 'SUA_CHAVE_AQUI'; // DEPOIS (com a chave real) const WEATHER_API_KEY = 'a1b2c3d4e5f6a1b2c3d4e5f6a1b2c3d4'; // exemplo

Arquivo js/news.js — Chave da GNews API

Abra o arquivo js/news.js e localize a linha 1:

// ANTES (placeholder) const NEWS_API_KEY = 'SUA_CHAVE_AQUI'; // DEPOIS (com a chave real) const NEWS_API_KEY = '9f8e7d6c5b4a9f8e7d6c5b4a9f8e7d6c'; // exemplo
Importante: não compartilhe as chaves reais publicamente (ex: no GitHub). As chaves acima são apenas exemplos ilustrativos.

Como executar o projeto

Após configurar as chaves, há duas formas de abrir o dashboard:

A
Via Live Server no VS Code (recomendado)

Instale a extensão Live Server (autor: Ritwick Dey) no VS Code. Clique com o botão direito em index.html → Open with Live Server. O browser abre em http://127.0.0.1:5500 e as APIs funcionam corretamente.

B
Duplo clique no index.html

Abre diretamente no browser via protocolo file://. O clima funciona normalmente. Para as notícias funcionarem por este método, pode ser necessário usar o Live Server dependendo do navegador.

Tudo certo quando: ao digitar uma cidade e clicar em Buscar, os cards de clima, previsão e gráfico são preenchidos. O feed de notícias aparece automaticamente ao carregar a página.

O Wireframe do Projeto

Explicação do arquivo wireframe.html — planejamento visual da interface

O arquivo wireframe.html é um documento HTML independente que representa o planejamento visual do dashboard — uma etapa de projeto que define a estrutura e o layout das telas antes da implementação real. Ele foi entregue como parte da atividade acadêmica da disciplina.

O que é um Wireframe

Um wireframe é um esboço de baixa fidelidade que mostra onde cada elemento estará na tela, sem cores, fontes ou imagens definitivas. Blocos cinzas representam áreas de conteúdo, retângulos com um "X" representam imagens, e linhas horizontais representam blocos de texto. O objetivo é validar a organização da informação antes de escrever o código real.

Conteúdo do wireframe.html

Página 1 — Capa

Capa do documento com título, nome do aluno, professor, disciplina, instituição e lista de tecnologias utilizadas no projeto.

Página 2 — Wireframe Desktop

Layout em grid 2×2 para resolução 1280×800 px. Mostra a navbar com busca, os 4 quadrantes (clima, previsão, gráfico, notícias) e o rodapé, todos em tons de cinza.

Página 3 — Wireframe Mobile

Mockup de smartphone (375×812 px) com layout em coluna única. Inclui hambúrguer no header, empilhamento de seções e scroll horizontal na previsão de 5 dias.

Página 4 — Setup Inicial

Documentação técnica original: estrutura de pastas, tabela de APIs, critérios de aceite e comandos Git para publicar o repositório no GitHub.

Diferenças entre o wireframe e a implementação final

O wireframe serve como referência de planejamento. A implementação real em index.html seguiu a mesma estrutura de grid 2×2 e as mesmas seções definidas no wireframe, com as adaptações naturais que surgem no desenvolvimento: ícones reais da OpenWeatherMap, dados dinâmicos via Fetch API, gráfico interativo via Chart.js e notícias reais via GNews API.
