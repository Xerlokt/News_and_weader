Adaptações Responsivas

Navbar
Menu hambúrguer substitui links horizontais. Campo de busca fica visível abaixo do header.
Grid 2×2 → Coluna única
Ordem de empilhamento: Clima Atual → Previsão → Gráfico → Notícias.
Previsão 5 Dias
Scroll horizontal via overflow-x: auto para não comprimir os cards dos dias.
Gráfico (Chart.js)
Height reduzido em mobile. Chart.js responsivo por padrão com responsive: true.
Cards de Notícias
Empilhados em coluna única. Thumbnail removido em telas < 360 px para economizar espaço.
Breakpoints definidos:
≤ 768px → Mobile (1 coluna)
769 – 1024px → Tablet (2 col. parcial)
≥ 1025px → Desktop (grid completo)

APIs e Bibliotecas

RecursoFinalidadeCusto
OpenWeatherMap Clima atual + previsão 5 dias Gratuito (1.000 req/dia)
NewsAPI.org Manchetes por país / tema Gratuito (100 req/dia)

LocalStorage Cidades favoritas (CRUD) Nativo do browser

Critérios de Aceite Atendidos

API Externa — OpenWeatherMap + NewsAPI
CRUD / Persistência — LocalStorage (favoritos)
Interface Responsiva — CSS Grid + Media Queries
Manipulação de DOM — Busca, filtros, estado dinâmico

Repositório Git

# 1. Inicializar repositório local git init git add . git commit -m "chore: setup inicial" # 2. Conectar ao GitHub e subir git remote add origin \ https://github.com/<usuario>/atv_labweb.git git branch -M main git push -u origin main
Antes do push: crie o repositório público em github.com com o nome atv_labweb (sem inicializar com README). O link do repositório deverá ser incluído na entrega ao professor.
